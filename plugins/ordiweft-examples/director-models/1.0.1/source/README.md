# 原创片场素材包

Apache-2.0 的自包含 GLB 样本。`models/triangle.glb` 是原创三角面，三个顶点为 (0,0,0)、(1,0,0)、(0,1,0)，不包含外部链接、贴图或脚本。样本用于验证分发和导入，不是生产资产目录。

使用 `ordiweft-plugin verify --root .` 检查完整清单，`ordiweft-plugin pack --root . --out ../director-models-1.0.1.zip` 打包。管理员安装、显式激活后，成员从3D资产库导入个人或团队模型库，再沿用现有「放入场景」操作。更新插件不覆盖已导入的模型或场景；同一所有者、范围和GLB摘要复用原资产。

包内 `models.json` 仅声明目录和许可。宿主读取原包、检查实际 GLB 字节，通过既有模型导入事务保存副本；内容包不执行代码、不下载远端文件。
