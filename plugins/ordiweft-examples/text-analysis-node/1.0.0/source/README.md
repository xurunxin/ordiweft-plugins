# 文本分析动作节点

原创 Apache-2.0 离线处理器与声明式节点，复用公开Host SDK 0.1.5及其NOTICE，不使用模型、网络或业务写入。只有analyze-text处理器入口；analysis节点以同包固定版本打开原处理器表单，同名字段草稿用于预填。运行前可在处理器表单试参，不自动保存节点、执行连线或回写结果。

管理员安装并显式启用后，从原节点目录新建「文本分析」。版本更新不改已有节点定义或原任务；旧版本退出活动目录时拒绝新的处理，不替换为新版。

在包目录运行 `ordiweft-plugin verify --root .`，以 `ordiweft-plugin pack --root . --out ../text-analysis-node-1.0.0.zip` 打包到包外新路径。安装后须另做原动作fixture验证；静态打包不证明功能测试、沙箱就绪或执行资格。
