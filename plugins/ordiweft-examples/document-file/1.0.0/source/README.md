# 结构文档导出私有文本候选

原创Apache-2.0样本，复用公开SDK 0.1.4和独立action协议，把title/paragraphs转换为UTF-8文本文件候选。使用受限outputs.begin/write/stage，不接路径、URL、文件名、MIME或业务assetId。宿主核对实际字节并保存私有原输出；不创建生成作业、素材业务引用或画布节点。

管理员暂存后运行包内固定fixture的独立合成验证，核对原值及实际11字节文本摘要；通过不激活。显式启用后成员仍经画布范围动作API提交，原任务done后可读取原输出附件。取消、撤权、unknown不重跑；文件采用与业务工具需另行接通。

无网络、秘密、输入资产、派生或远程worker。资源申请1个输出、4MiB和60秒，宿主可以施加更小限制。文件说明不表示完整文档格式转换、PDF/OCR或大文件流已交付。
